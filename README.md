# 📦 Inventory & Supply Chain Analysis Dashboard

This project is one of the most practical Power BI projects I've worked on. Instead of just creating charts, I wanted to build a dashboard that tells a story about inventory and supply chain performance and helps answer real business questions.

The goal was to transform raw data into meaningful insights that someone in operations or management could use to make better decisions.

---

## 🚀 About the Project

The dashboard focuses on understanding how inventory moves through the business and how different aspects of the supply chain are performing.

Using Power BI, I cleaned the data, built relationships between tables, created DAX measures, and designed an interactive dashboard that allows users to explore the data with filters and slicers.

Some of the insights include:

- Inventory status
- Product performance
- Sales trends
- Supplier performance
- Stock distribution
- Overall business KPIs

---

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

---

## 📚 What I Learned

This project helped me understand that Power BI is much more than creating charts. I learned how important it is to prepare the data before building any visualization.

One of my biggest takeaways was that a good dashboard should answer business questions quickly without overwhelming the user with too much information.

---

## 📊 Dashboard Features

The dashboard includes:

- Interactive KPI Cards
- Inventory Analysis
- Sales Analysis
- Supplier Performance
- Product wise Analysis
- Category wise Insights
- Dynamic Filters & Slicers
- Business friendly Visualizations

---

## 🎯 Business Questions Answered

This dashboard helps answer questions like:

- Which products perform the best?
- How is inventory distributed?
- Which suppliers are performing well?
- What are the overall sales trends?
- Which categories contribute the most to inventory?
- Where can inventory management be improved?

This project was a great learning experience and gave me hands on exposure to the complete Power BI workflow—from importing raw data to building a polished, interactive dashboard.

More importantly, it taught me to think like a business analyst rather than just a report developer. Every chart and KPI was created with the goal of helping users make informed decisions.
